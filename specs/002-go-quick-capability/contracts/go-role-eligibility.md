# Contract: OpenCode Go Thinking-Role Eligibility

## Catalog Interface

The Go model-options interface accepts a requested thinking role.

| Input | Output |
|---|---|
| Quick | All reviewed Go IDs except reviewed Messages IDs without ordinary tools. |
| Deep | Every reviewed Go ID. |

Labels continue to disclose the reviewed protocol and no Custom model option is
added.

## Validation Interface

The Go metadata exposes a pure validation operation for the configured Quick
model.

| Configured ID | Result |
|---|---|
| Reviewed tool-capable Quick model | Returns successfully. |
| Reviewed Messages model without ordinary tools | Raises a clear Go configuration error before initialization. |
| Unknown ID | Returns successfully so the existing strict factory error remains authoritative. |

## Graph Boundary

Graph construction invokes the Quick validation only when the selected provider
is OpenCode Go, before updating interface configuration, creating directories,
building clients, fetching data, constructing tools, or making any network
call.
